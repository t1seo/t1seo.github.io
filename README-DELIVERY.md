# 종이 작업실 실행 안내

시간과 계절에 따라 풍경이 바뀌는 개인 포트폴리오입니다. 화면 속 물건을 눌러 작은 반응을 발견하고, 기존 사원증을 아래로 당겨 포트폴리오를 열 수 있습니다. 포트폴리오는 순백색 바탕과 흑백 구성, Work Sans 제목을 사용한 별도 페이지입니다.

## 처음 실행하기

1. 전달받은 압축 파일을 해제합니다.
2. **Node.js 22.12 이상**을 설치합니다. 이 프로젝트는 Vite 8과 TypeScript를 사용합니다.
3. 터미널에서 압축을 푼 폴더로 이동합니다. `package.json`이 보이는 폴더가 맞습니다.
4. 아래 명령을 차례대로 실행합니다.

```sh
npm ci
npm run dev
```

`npm ci`는 필요한 개발 도구를 설치하므로 처음에는 인터넷 연결이 필요합니다. 실행 후 브라우저에서 **http://localhost:5173**을 여세요. 해당 포트가 이미 사용 중이면 터미널에 표시된 주소를 사용하시면 됩니다. 서버를 종료하려면 터미널에서 `Ctrl+C`를 누릅니다.

환경 변수 파일(`.env`), API 키, 별도 계정이나 데이터베이스는 필요하지 않습니다. 사용 중인 그림·종이 질감·글꼴·음원 파일은 프로젝트에 포함되어 있습니다.

## 완성본 만들기와 미리보기

```sh
npm run build
npm run preview
```

`npm run build`는 타입을 확인한 뒤 배포용 파일을 `dist/` 폴더에 만듭니다. `npm run preview`를 실행한 다음 **http://localhost:4173** 또는 터미널에 표시된 주소를 열면 빌드 결과를 볼 수 있습니다.

배포할 때는 `dist/` 안의 파일 전체를 정적 웹 서버의 루트에 올리시면 됩니다. `index.html`을 더블 클릭해 여는 방식은 사용하지 마세요. 자바스크립트와 `/assets/` 경로를 정상적으로 읽으려면 개발 서버, 미리보기 서버 또는 정적 웹 서버를 통해 접속해야 합니다.

## 둘러보기

- 벽 달력을 누르면 시간대 5개, 계절 4개, 움직임과 음악 설정을 바꿀 수 있습니다. 물건 목록, 포트폴리오와 출처 페이지도 여기에 있습니다.
- 램프, 모니터, 키보드, 커피잔, 책, 지구본 등 18곳에 반응이 숨어 있습니다. 메모는 누르거나 `Esc`를 눌러 닫을 수 있습니다.
- 음악은 직접 켰을 때만 재생됩니다. 계절과 시간대에 맞춰 공개 라이선스 음원 20곡 중 한 곡을 재생합니다.
- 사원증은 눌러 뒤집거나 끌어 흔들 수 있습니다. 아래로 충분히 당기면 포트폴리오가 열립니다. 사원증에 키보드 초점이 있을 때 `↓`를 누르거나 달력의 포트폴리오 버튼으로도 이동할 수 있습니다.
- 이름과 역할 소개는 작업실을 클릭하거나 터치하면 사라지고, 30초 동안 조작하지 않으면 다시 나타납니다.

## 실제 내용으로 바꿀 곳

현재 포트폴리오의 **프로젝트 3개와 경력 2개는 예시 내용**입니다. 실제 작업과 경력으로 교체한 뒤 공개해 주세요.

| 바꿀 내용 | 파일 |
|---|---|
| 프로젝트, 소개 문장, 경력 | `src/paper-portfolio.ts` |
| 처음 보이는 이름과 역할 문구 | `src/paper-intro.ts` |
| 사원증의 내용과 동작 | `src/badge.ts` |
| 물건 위치와 장면 반응 | `src/paper-scene.ts`, `src/paper-scene.css` |
| 계절·시간대별 음악 연결 | `src/paper-music-catalog.ts` |

## 사용한 자료와 출처

현재 사용하는 공개 풍경 일러스트와 실제 종이 스캔, 라이선스 음원과 글꼴을 함께 제공했습니다. 실내 기본 그림과 현재 소품 6개(트리·리스·호박·꽃·고양이·참새)는 이미지 생성 도구로 제작했으며, 공개 작가 에셋과 구분해 기록했습니다. 소품은 원래 방의 질감·조명·색감에 맞췄습니다. 고양이는 러그 위에서 쉬는 펠트 질감의 모습이며, 여름에는 기존 액자 안의 종이 프린트가 바뀝니다.

이전에 시험했던 공개 빈티지 소품 7개와 Kitbitz 자료는 출처 기록과 함께 보관되어 있습니다. 현재 장면에 사용하는 소품으로 소개하지 않습니다.

- 그림·질감·글꼴: `public/assets/paper/CREDITS.html`
- 현재 생성 소품의 제작 기록: `public/assets/paper/decor/studio-matched/NOTICE.md`
- 곡별 작곡가·원본·라이선스: `public/assets/music/CREDITS.html`
- 구현과 자료 설명: `docs/PAPER-STUDIO.md`

배포할 때 위 크레딧과 함께 제공된 라이선스 파일도 유지해 주세요. 특히 창밖 풍경과 음악에는 CC BY 4.0 출처 표시가 포함되어 있습니다.

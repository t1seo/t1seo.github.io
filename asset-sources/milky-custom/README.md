# Original Milky character study

Created 2026-10-02. This is an editable **local prototype**, not the deployed pet.
See [the implementation report](../../docs/MILKY-CUSTOM-PROTOTYPE.md) and the
[original proposal](../../docs/MILKY-CUSTOM-CHARACTER-PROPOSAL.md).

## Source and provenance

- The body, ears, muzzle, eyes, nose, skeleton, coat atlas and two actions are
  generated by the scripts in this folder. No Shiba mesh, stock animation, paid
  character, photogrammetry service or external image generation is used.
- Twenty-seven owner-supplied photographs were inspected locally. The standing
  full-body and trimmed front-face views anchor the proportions. Coat length
  differs between photographs; the study uses the shorter body coat and longer
  ear/tail hair. The images are visual references, not measured orthographic scans.
- Private source photographs and the local reference board are **not included**
  in the repository, GLB, texture or preview. The coat atlas is original procedural
  linework, not a photograph-derived texture.
- The software is Blender **4.5.9 LTS**, official macOS ARM64 distribution.
  Installer SHA-256:
  `e3a3d7aac381fb4e4d05197f99cd8899484d7e8bc4497c134066e6733f372238`.
  [Official distribution](https://download.blender.org/release/Blender4.5/).
- Three.js is the repository's existing dependency. Its GLTFLoader,
  AnimationMixer and OrbitControls power the isolated preview.

the main site's entry point.

## Rebuild and review

From the repository root, using the installed Blender executable:

```sh
export TMPDIR=/Volumes/Nebula/Developer/Temp/
export TMP=/Volumes/Nebula/Developer/Temp/
export TEMP=/Volumes/Nebula/Developer/Temp/
/Volumes/Nebula/Developer/Tools/Blender-4.5.9/Blender.app/Contents/MacOS/Blender \
  --background --threads 4 --python asset-sources/milky-custom/build.py
node asset-sources/milky-custom/verify-export.mjs
npm run dev -- --port 5173 --strictPort
```

Open `http://127.0.0.1:5173/experiments/milky-custom/index.html?autoplay=0`.
Choose a camera, original coat/clay/wireframe, Idle or Walk, then play or scrub.
The room option is a **backdrop comparison**, not a floor-registered integration.

Rebuilding overwrites `milky-master.blend` and the generated files. Save manual
sculpting as a separate `.blend` before rebuilding; port accepted edits back to
the construction script or preserve them as an explicit later authoring stage.

## Animation convention

Authoring: Z up, +X toward the nose, +Y animal's left. Export: Three.js Y up.
The walk is 1.4 seconds, with virtual root travel of 0.46 model units; metadata
records that distance. The clip stays in place for inspection. A future route
controller must translate it at `0.46 / 1.4` model units/second at 1× playback.
Playing it in place does not itself demonstrate world-space foot locking.

The 33-bone armature is custom rather than the proposal's suggested Rigify
metarig. Explicit rest transforms make this initial procedural study reproducible.
It includes chest/pelvis/spine, shoulder blades, separate front and hind limb
chains, paws/toes, head/neck, ears, jaw and tail. Rigify-style artist controls,
corrective shapes and manual skin-weight cleanup are not implemented.

The source gait uses four contact phases, constant stance velocity and smooth
swing paths. Two-bone IK preserves limb lengths while the pelvis, chest and
shoulders move; neck/head counter-motion and small ear/tail follow-through are
baked into the clips. These are authored choices, not captured Milky motion.

The coat uses a masked texture with mipmaps. At browser review distances the
original alpha cutoff of 0.28 discarded nearly all fine strands; 0.08 restores
them. Alpha-to-coverage produced conspicuous white speckling in the tested Orca
surface and is disabled. Coat quality and aliasing at other scales remain a
visual refinement task.

## Boundaries

The independent verifier checks both actions, all exported skinned vertices,
weights, loops, contact trajectories and floor bounds. It removes image and
material references **in memory** to run in Node. A numerical pass is not a
likeness, texture, naturalness or frame-rate certification.

This first study does not implement the remaining production behaviors, turning,
starts/stops, ground correction in the room, failure fallback or mobile profiling.
The current topology also exceeds the proposal's initial triangle target.

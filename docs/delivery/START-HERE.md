# Taewon Seo — After Hours

밀키와 함께하는 작업실 프로젝트입니다. 압축을 푸신 뒤 아래 방법으로 열어 주세요.

- `project/`: 수정 가능한 전체 소스, 이미지·음악·폰트, 실행에 필요한 설정과 빌드 결과입니다.
- `project/dist/`: 설치 없이 로컬 웹 서버에서 볼 수 있는 완성된 웹사이트입니다.
- `logos/`: A·B·C 로고의 PNG/WebP 파일과 미리보기입니다. 하얀 귀의 **A가 페이지 로고와 파비콘**으로 적용되어 있습니다. B·C의 하얀 버전과 이전 버전도 함께 보관되어 있습니다.
- `logos/active-icons/`: 현재 사용 중인 64px 파비콘과 180px Apple Touch 아이콘입니다.
- `MANIFEST.json`: 소스 버전과 각 파일의 크기·SHA-256 확인값입니다.

## 완성된 페이지 바로 보기

Python 3가 설치되어 있다면 터미널에서 압축을 푼 폴더의 `project/dist`로 이동한 후 실행해 주세요.

```sh
python3 -m http.server 5174 --bind 127.0.0.1
```

**Chrome**에서 <http://127.0.0.1:5174/>를 열어 주세요. 종료할 때는 터미널에서 `Control + C`를 누르시면 됩니다. `dist/index.html`을 더블 클릭하면 이미지나 스크립트 경로가 동작하지 않을 수 있으므로 웹 서버로 열어 주세요.

이미 5174번 포트를 사용하고 있다면 명령의 `5174`를 `5175`로 바꾸고, Chrome에서도 <http://127.0.0.1:5175/>를 열어 주세요.

## 코드를 수정하며 보기

Node.js 22.12 이상 또는 호환되는 최신 LTS 버전이 필요합니다. 터미널에서 `project` 폴더로 이동한 뒤 한 줄씩 실행해 주세요. 처음 설치할 때에는 인터넷 연결이 필요합니다.

```sh
npm ci
npm run dev -- --port 5174
```

Chrome에서 <http://127.0.0.1:5174/>를 열어 주세요. Vite가 다른 포트를 표시하면 터미널에 나온 주소를 사용하시면 됩니다.

수정한 내용을 완성본으로 다시 만들려면 다음 명령을 실행해 주세요.

```sh
npm run build
```

## 작업실 둘러보기

시간·계절·날씨 메뉴에서 실내외 분위기를 바꿔 보세요. 책상 위의 모니터, 컵, 스피커, 싱잉볼, 만년필을 눌러 작은 변화를 발견하실 수 있습니다. 음악은 스피커를 눌렀을 때 재생됩니다.

하단 `Desk` 메뉴(작은 화면에서는 네 칸 모양 아이콘)에는 밀키와 인사하고, 앉기·잠자기·식사·공놀이·달리기를 시도할 수 있는 동작이 모여 있습니다. 밀키를 직접 눌러 인사하실 수도 있습니다. 기기의 동작 줄이기 설정을 켜면 움직임이 줄어듭니다.

로고 비교 페이지는 <http://127.0.0.1:5174/milky-logo-options.html>에서 볼 수 있습니다. 로고만 보실 때에는 `logos/index.html`을 더블 클릭하셔도 됩니다.

## 파일과 권리 안내

음악·폰트·공개 에셋의 출처와 라이선스는 `project/public/assets/` 및 `project/docs/`에 함께 보관되어 있습니다. 공개하거나 재사용하실 때 해당 출처 안내도 유지해 주세요. 밀키의 개인 원본 사진·영상, 로그인 정보, 개발 도구의 개인 설정, `node_modules`는 이 압축파일에 넣지 않았습니다.

이전 Jieun 작업실의 일부 소스·에셋은 프로젝트의 이력과 재사용을 위해 소스 폴더에 남아 있습니다. 기본 실행 화면은 Taewon Seo의 현재 작업실입니다.
